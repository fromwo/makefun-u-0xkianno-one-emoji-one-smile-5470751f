This program writes exactly one emoji, 🤗, to `/output/entry.txt` and nothing else. I picked the hugging face because its open arms and bright smile read instantly as a warm, welcoming hug from a stranger, with no context, irony, or intimacy needed to understand it. It feels deliberately chosen rather than a default smiley, yet anyone of any age can read its friendliness at a glance, which is why it is the emoji most likely to make a stranger smile.

## Run it

```sh
node main.ts
```
